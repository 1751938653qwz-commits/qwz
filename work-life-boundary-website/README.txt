Work-Life Boundary · 工作与生活边界
====================================

一个基于摄像头人体识别的互动网页艺术项目。
职场文字像雨一样从屏幕落下，你的身体可以阻挡它们。

功能说明
--------
1. 摄像头识别人体（TensorFlow.js + BodyPix）
2. 职场文字从顶部匀速下落（中英文混合）
3. 身体阻挡文字（碰到人体轮廓即停止）
4. 保持不动超过8秒 → 弹出 "Continue working" 提示框
5. 办公消息提示音（Web Audio API 合成）

使用方法
--------
1. 用 Chrome/Edge 浏览器打开 index.html
2. 允许摄像头权限
3. 等待3秒，文字开始下落
4. 移动身体阻挡文字
5. 保持静止8秒触发提示框

文件说明
--------
index.html  - 主页面（所有代码都在这个文件中）

技术要求
--------
- 现代浏览器（Chrome / Edge）
- 需要摄像头
- 需要网络（加载 TensorFlow.js 和 BodyPix 模型）
